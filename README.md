# CarDJ seed catalog

Static catalog read by the CarDJ app (`kr.ltech.cardj`) until its backend is live.

- `catalog.json` — track list. Each entry carries the measured audio quality (from CarDJ's own quality-check pipeline), the licence and the source page.
- `audio/` — the audio files, unmodified from the source.
- `CREDITS.md` — attribution for every track.

Every track was published by its author on ccMixter under a Creative Commons Attribution licence. Tracks whose remix sources are not licensed for commercial reuse, or that fail the quality check, are not included.
